# Pixel Archery

یک بازی آرکید تیر و کمان با گرافیک پیکسلی. فایل `index.html` را در مرورگر باز کنید؛ به نصب یا اتصال اینترنت نیاز ندارد.

- با ماوس یا لمس نشانه بگیرید و برای شلیک رها کنید.
- برای بازی با صفحه‌کلید، با Tab میدان بازی را انتخاب کنید، با کلیدهای جهت‌دار هدف بگیرید و کلید فاصله را فشار دهید و رها کنید.
- هر دور ۱۰ تیر دارد و هر تیر حداکثر ۱۰ امتیاز می‌گیرد. بهترین امتیاز در صورت دسترسی به حافظهٔ مرورگر ذخیره می‌شود.
- با Escape بازی را متوقف کنید یا ادامه دهید.
