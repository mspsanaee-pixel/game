# 🏹 تیر و کمان — بازی تیراندازی (HTML)

یک بازی کامل و تک‌صفحه‌ای با **HTML + CSS + JavaScript خالص** (بدون هیچ کتابخانه یا فایل خارجی).
با کمان به سیبل تیر بزن، امتیاز بگیر و رکورد خودت را بشکن.

## اجرا

فقط `index.html` را در مرورگر باز کن. اگر مرورگر فایل‌های محلی را محدود کرد، یک سرور ساده اجرا کن:

```bash
python3 -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

## نحوهٔ بازی

| عمل | کنترل |
| --- | --- |
| کشیدن کمان و شلیک | دکمهٔ ماوس (یا لمس انگشت) را نگه دار و رها کن |
| نشانه‌گیری | جابه‌جایی نشانگر، قبل یا در حین کشیدن کمان |
| شلیک با کیبورد | `Space` (نگه دار و رها کن) + کلیدهای جهت برای تنظیم نشانه |
| صدا | کلید `M` یا دکمهٔ بلندگو |
| شروع دوباره | کلید `R` |

## قواعد

- ۱۲ تیر در هر بازی؛ به ازای هر تیر یک امتیاز.
- حلقه‌ها از مرکز به بیرون: **طلا ۱۰، قرمز ۸، آبی ۶، مشکی ۴، سفید ۲**.
- جاذبه تیر را پایین می‌کشد و باد آن را منحرف می‌کند؛ قبل از شلیک جهت و شدت باد را از نوار بالای صفحه ببین.
- سیبل هر تیر جابه‌جا می‌شود و با پیشرفت بازی دورتر و متحرک‌تر می‌شود.
- بهترین رکورد در `localStorage` ذخیره می‌شود.

## نکات فنی

- رندر تمام صحنه با **Canvas 2D** و مقیاس‌پذیر تا `devicePixelRatio` ۲.
- فیزیک تیر با گام زمانی ثابت ۴ میلی‌ثانیه و تشخیص برخورد در همان گام‌ها (بدون تونل‌زدن از سیبل).
- صداها به‌صورت زنده با **WebAudio** سنتز می‌شوند (بدون فایل صوتی).
- طراحی واکنش‌گرا برای دسکتاپ، تبلت و گوشی؛ در حالت عمودی راهنمای چرخش نمایش داده می‌شود.
- برای فعال کردن قلاب اشکال‌زدایی: `index.html?debug` (شیء `window.__archery`).

## ساختار پروژه

```
index.html   اسکلت صفحه، HUD، صفحهٔ شروع و پایان بازی، آیکون‌های SVG
style.css    استایل رابط کاربری، واکنش‌گرایی و انیمیشن‌ها
game.js      منطق بازی، فیزیک، رندر صحنه، صدا و مدیریت وضعیت
```
